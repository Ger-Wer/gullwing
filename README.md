Gullwing — a coastal light-plane flight game. You fly a single-engine gull-wing plane over Kestrel Bay at golden hour: take off from RWY 09, thread glowing rings, run the mountain pass at low level, and watch the fuel. Chase or cockpit view, lit instruments, stalling, damage, and three sorties with different goals.

## Play

- **Throttle** — W / S, or the mouse wheel
- **Pitch** — Up / Down (or I / K)
- **Roll / turn** — Left / Right (or A / D)
- **Brakes on the deck** — SPACE
- **Camera** — C (chase / cockpit) · **Mute** — M
- **Choose a sortie** — 1 / 2 / 3, launch with **Enter**

Sortie 1: take off from RWY 09, loop the two bay checkpoints, land back in the green. Sortie 2: thread all six rings before the fuel is gone. Sortie 3: run the pass at low level for the low-flight bonus. Every hard touchdown costs hull; a dead engine leaves you a glide.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
